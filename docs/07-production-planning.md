## Policy comparison: the same October, run twice

Same orders, same seed. Only the purchasing rule differs.

| | As-is: bulk order when retailer payments come in | To-be: joint reorder point, one Gujarat load |
|---|---|---|
| Idle production (sheet stockouts) | 1.5 days, ₹41,225 | 0.0 days, ₹0 |
| Emergency local buys (8% premium) | 2 (₹12,464) | 1 (₹3,480), during the switch-over only |
| Gujarat loads / freight | 3 / ₹16,000 | 3 / ₹16,000 |
| Units delivered | 210 | 209 |

**About ₹50,209 a month recovered** (idle salary + emergency premium) with no extra freight. (The CNC breakdown day is the same in both runs and is excluded above.)

A first version of the policy ordered each item separately the moment it crossed its reorder point. That removed the stockouts but tripled Gujarat loads (10 loads, ₹56,000 freight). Joint replenishment, where any item at its reorder point triggers one consolidated load at most weekly, keeps freight flat. That trade-off is why the policy is joint.
